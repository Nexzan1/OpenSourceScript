# 🚀 Nexzan Hub — Open Source Roblox Script Collection

Selamat datang di repository resmi **Nexzan Hub (Open Source Version)**. Repository ini berisi kumpulan script Roblox buatan komunitas yang dikembangkan secara terbuka untuk tujuan pembelajaran dan pengembangan bersama.

---

## 📜 Script Utama / Feature Script

### 🚀 Swing For Egg Script
Script khusus untuk game **Swing For Egg** yang siap langsung dieksekusi melalui executor pilihanmu (Android/Mobile & PC).

#### 🔹 Quick Loadstring
Copy dan tempel kode berikut ke dalam executor kamu:

```lua
loadstring(game:HttpGet("https://nexzan-hub-only.netlify.app/api/raw/0GzB7cq9Zg"))()
```
